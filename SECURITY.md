# Security policy

**This project is not actively maintained or funded; support is best effort.**

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub:
**Security → Report a vulnerability** on
[rAum/radveil-slicer](https://github.com/rAum/radveil-slicer/security). Do not
open a public issue.

Please include the extension version (or commit), the Slicer version and
operating system, and steps to reproduce. Problems in the `radveil` package
itself belong to [rAum/radveil](https://github.com/rAum/radveil/security).

## Supported versions

Fixes go into the latest release. There is no long-term-support branch.
